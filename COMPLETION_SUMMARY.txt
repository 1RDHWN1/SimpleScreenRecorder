🛠️ CUSTOMIZATION QUICK TIPS
───────────────────────────────────────────────────────────────

Change Default FPS:
  → Edit src/MainForm.cs, line ~64: fpsSpinner.Value = 60;

Change Default Quality:
  → Edit src/MainForm.cs, line ~72: qualitySlider.Value = 95;

Add New Codec:
  → Edit src/RecordingSettings.cs, GetCodecName() method

Change Output Folder:
  → Edit src/MainForm.cs, constructor, outputDir variable
